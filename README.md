# 💻 Proyectos Académicos - Carrera en Tecnología

Bienvenido/a a este repositorio, donde comparto parte de mi recorrido académico a través de distintos trabajos prácticos y proyectos desarrollados durante el cursado de materias orientadas a la programación, desarrollo web, bases de datos y arquitectura de computadoras.

---

## 📚 Materias y Contenidos

### Programación 1
Introducción a la lógica de programación utilizando **Python**.  
En esta materia aprendí a:
- Resolver problemas aplicando pensamiento lógico.
- Interpretar y trabajar con diagramas de flujo.
- Crear soluciones mediante código Python.
- Iniciar el camino en estructuras de datos básicas.

🧠 *Lenguaje utilizado:* Python  

---

### Arquitectura de Computadoras
Exploración del mundo de la informática desde sus conceptos fundamentales hasta sus aplicaciones prácticas.  
Habilidades desarrolladas:
- Identificación y análisis de componentes de hardware.
- Configuración y optimización del sistema utilizando software específico.
- Introducción a la creación de sitios web con **HTML y CSS**.

🖥️ *Tecnologías vistas:* Hardware, sistemas operativos, HTML y CSS.  
📁 *Trabajos incluidos:* análisis de componentes, actividades prácticas de configuración y páginas web básicas.

---

### Programación 2
Profundización en los principios de la **programación orientada a objetos** con **Java**.  
Conceptos aplicados:
- Encapsulamiento, herencia y colaboración entre clases.
- Uso de librerías gráficas para el desarrollo de interfaces.
- Creación de formularios utilizando generadores visuales.

☕ *Lenguaje utilizado:* Java  
📁 *Trabajos incluidos:* clases y objetos, interfaces gráficas (Swing, AWT), patrones de diseño simples, POO.

---

### Aplicaciones Web
Diseño y desarrollo de sitios web estáticos.  
Aprendí a:
- Maquetar sitios con **HTML5**.
- Dar estilo y responsividad con **CSS3**.
- Incorporar interactividad básica con **JavaScript**.

🌐 *Tecnologías utilizadas:* HTML, CSS, JavaScript  
📁 *Trabajos incluidos:* landing pages, portfolios, páginas informativas.

---

### Programación Móvil
Desarrollo de aplicaciones para dispositivos Android utilizando **Java y Eclipse**.  
Temas abordados:
- Actividades (Activity), layouts y componentes visuales.
- Manejo de eventos e interacciones.
- Almacenamiento interno y gráficos en pantalla.

📱 *Tecnologías utilizadas:* Java para Android, Eclipse IDE  
📁 *Trabajos incluidos:* apps simples con navegación, formularios y persistencia de datos.

---

### Base de Datos 1
Introducción al mundo de las **bases de datos relacionales** y el lenguaje **SQL**.  
Capacidades adquiridas:
- Diseño de modelos entidad-relación.
- Normalización de bases de datos.
- Consultas SQL (SELECT, JOIN, GROUP BY, etc.).

🗃️ *Tecnologías utilizadas:* SQL, modelado E/R  
📁 *Trabajos incluidos:* esquemas relacionales, scripts de creación y consultas a bases de datos.

---

## Cómo navegar el repositorio

Cada carpeta dentro de este repositorio corresponde a una materia distinta y contiene los archivos de código fuente, documentación y/o capturas según el caso. Podés explorarlas libremente para conocer más sobre cada proyecto.
